# 蚂蚁货架监测

面向华安基金运营人员的蚂蚁货架监测平台。总览包含五张宏观指标卡、五张一级货架分类卡和六个分析模块，提供公司与货架下钻、来源核验和跨榜矩阵。另保留天天基金公开数据后台测试接口。

## 本地构建与检查

使用 Node.js 22 或更新版本，无需安装依赖。

```sh
npm run build
npm test
```

`public/` 保存界面和图片，`worker/index.js` 保存后台逻辑。构建将静态资源嵌入 `dist/server/index.js`，导出 Cloudflare Worker 的 `fetch` 处理器。

## 接口

- `GET /api/health`：后台运行状态。
- `GET /api/funds/012229`：由后台实时请求天天基金公开数据，返回基金名称、最新净值、净值日期、日收益百分数、历史记录数及取数时间。

这些接口未使用本地缓存结果替代线上取数。净值日期与请求时间分开返回；数据源不可用时返回 HTTP 502。公开数据接口的长期可用性和字段口径需要持续核对。

## 发布

### GitHub Pages 快照

运行 `npm run build:pages` 生成 `docs/` 静态快照并提交。仓库 Settings → Pages → Source 选择 Deploy from a branch，分支 `main`，目录 `/docs`。快照使用已有名单数据，实时取数接口不在 GitHub Pages 上运行。更新快照后需重新构建并推送 `docs/`。

### 完整后台版本

当前运行于 Sites，发布权限由 Sites 管理。源码同步到 GitHub 不会自动触发 Sites 部署。可将构建产物部署至支持 Worker ESM 的运行环境；GitHub Pages 仅支持静态页面，不能执行本项目后台。

仓库以 `public/data/shelves.json.gz` 保存页面使用的解析快照，构建时自动解压为JSON。不包含原始业务 Excel、批量净值下载缓存或访问凭证。运行环境凭证应单独配置，不能放入浏览器代码。

## 工作簿名单导入

使用带 openpyxl 的 Python 环境运行 `python scripts/import_workbook.py <工作簿路径>`，生成 `public/data/shelves.json`。该数据属于名单快照，不由天天基金净值接口生成，也不根据净值刷新时间更新名单日期。

导入读取全部工作表，以“求赚安稳盈”“求稳货架”的明确状态列、“风格化固收+”独立名单，以及经用户确认的“求赚固收+”四个波动分组建立关系。养老险和投顾组合排除，FOF保留。金选固收+含极低波、低波、中波、高波，二级榜单可重叠，一级货架内仍按代码去重。

按六位基金代码去重，未可靠合并份额。名单日期均未确认，跨来源合计只作为工作簿阶段性汇总。用户确认的双二级榜单分别统计；公司按名称前缀和明确别名归一，尚未核实管理人法人主体。货架详情支持当前在架与本期出池切换、搜索排序、产品详情、加入对比，并按原表分段表头读取字段和准入规则。导航更新时间来自实际导入时间。

`npm test` 验证去重、席位、排名、冲突、货架字段和后台契约。`node tests/browser.mjs` 为可选浏览器验收，需另行安装 Playwright，并使用本机 Edge；不属于运行时依赖。`npm run build` 后可运行 `node scripts/preview.mjs`，在 `http://127.0.0.1:4178` 查看本地页面。
