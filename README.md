# 蚂蚁货架监测

面向华安基金运营人员的蚂蚁货架监测平台。当前包含总览、货架、公司、对标分析四个空白页面，以及天天基金公开数据后台测试接口。

## 本地构建与检查

使用 Node.js 22 或更新版本，无需安装依赖。

```sh
npm run build
npm test
```

`public/` 保存界面和图片，`worker/index.js` 保存后台逻辑。构建将静态资源嵌入 `dist/server/index.js`，导出 Cloudflare Worker 的 `fetch` 处理器。

## 接口

- `GET /api/health`：后台运行状态。
- `GET /api/funds/012229`：由后台实时请求天天基金公开数据，返回基金名称、最新净值、净值日期、日收益百分数、历史记录数及取数时间。

这些接口未使用本地缓存结果替代线上取数。净值日期与请求时间分开返回；数据源不可用时返回 HTTP 502。公开数据接口的长期可用性和字段口径需要持续核对。

## 发布

当前运行于 Sites，发布权限由 Sites 管理。源码同步到 GitHub 不会自动触发 Sites 部署。可将构建产物部署至支持 Worker ESM 的运行环境；GitHub Pages 仅支持静态页面，不能执行本项目后台。

公开仓库不包含业务 Excel、基金批量原始数据或访问凭证。运行环境凭证应单独配置，不能放入浏览器代码。
